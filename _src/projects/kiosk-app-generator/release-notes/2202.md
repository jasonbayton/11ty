**Fixes**

- Dense app grids no longer clip or overlap their icons. On a very dense grid each icon now shrinks to fit its cell instead of overflowing, and when a cell is too narrow to show a readable label the label is dropped, so the grid stays a clean icons-only layout rather than icons over dark bars.
- The Studio live preview now matches the built app on dense grids, so the layout you design is the layout you get.
