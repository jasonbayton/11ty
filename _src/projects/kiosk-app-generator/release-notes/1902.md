_Covers releases 1.9.0 to 1.9.2._

**Features & improvements**

- The build-success screen now makes the update code prominent and makes downloading the app configuration the primary save action, explaining that retaining the code is required to update the same app on existing devices. The APK download is now held behind a one-time prompt until the code has been copied, the configuration downloaded, or the warning acknowledged.

**Fixes**

- The Studio download guard can no longer be bypassed by a second click, and a failed clipboard copy no longer counts as saved, showing a clear failure message rather than a misleading success.
