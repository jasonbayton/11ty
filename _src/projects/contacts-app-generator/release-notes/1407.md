_Covers releases 1.4.0 to 1.4.7._

**Features & improvements**

- **Clear managed-configuration status.** The EMM now receives the specific invalid field when a push is rejected and a recovery signal when a later push is accepted. These reports contain no contact data or source URLs.

**Fixes**

- **Safer managed configuration.** Invalid, partial or wrongly typed managed-configuration pushes retain the last known good configuration. If none exists, the app skips the sync rather than applying defaults. An explicit empty sources list remains a valid instruction to clear the current directory only when delete-missing is enabled.
- **Actionable build-failure guidance.** Recognised signing failures now show targeted, fixed guidance instead of a generic build failure. Unrecognised failures keep the generic message.
- **More reliable managed contact updates.** Removing, clearing or reconfiguring a source, or renaming its account, no longer leaves its contacts empty when it is added again or changed.
- **Validated configuration values.** Invalid network timeouts and sync intervals are rejected before they can create an unusable app, and invalid imported or saved Studio values no longer cause a crash loop.
