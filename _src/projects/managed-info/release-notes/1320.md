**Features & improvements**

- Improved System Freshness update reporting: availability is evaluated against the installed patch level, unavailable Google Play system-update information is identified clearly, and raw update-provider results can be inspected from the dashboard.
- Improved System Freshness CVE-report loading and caching. Valid cached data remains available offline; stale data refreshes when connectivity is available; and refresh operations are time-bounded and cannot overlap.

**Fixes**

- Prevented Android backup and device-to-device transfer from restoring MANAGED INFO state to a replacement device. This avoids a transferred device identifier updating the source device's record.
- Corrected the System Freshness loading-indicator animation target.
