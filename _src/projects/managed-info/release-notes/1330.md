**Features & improvements**

- Added Display overrides. Administrators can configure a Layout JSON experience to replace the normal MANAGED INFO home screen, or show it as a timed modal through App Actions.
- Display-override modals can be shown above an active full-screen override and return to it when dismissed or timed out.
- Added managed-configuration validation for display-override identifiers and Layout JSON size limits.

**Fixes**

- Improved display-override timing, expiry handling, and foreground text colour handling for custom themes.
- Preserved the underlying MANAGED INFO screen behind standalone display-override modals.
