**Features & improvements**

- Layout nodes can now trigger configured App Actions, including sounds, display-override modals, and managed HTTPS webhooks.
- Added reusable webhook definitions with JSON request bodies, optional headers, cooldowns, and limits on concurrent requests. External callers require an explicitly enabled definition and a matching App Actions token. Webhook requests are sent once, with no offline queue or automatic retry.
- Added animated GIF and WebP support to Layout image nodes, including cards, display-override modals, and fullscreen layouts. Animated WebP requires Android 9 or later. Animation is bounded by resource limits and follows screen visibility and lifecycle state.
- Added PING error reporting to help diagnose app failures, including fatal-crash capture and upload after the app restarts.
- Updated Coil to 2.7.0 and the Android Management API SDK to 1.9.0.

**Fixes**

- Fixed the usage-access Settings round trip during enrolment. Returning from Settings now preserves the usage-access screen instead of jumping back to the enrolment review.
- Corrected System Freshness patch-level comparisons for Google Play system updates and scoped provider check timestamps to the relevant component.

**Known issues**

- A failed managed-configuration save can prevent an unchanged policy from being retried and leave the previous policy active. Tracked in [#129](https://github.com/baytonorg/org.bayton.managedinfo/issues/129).
