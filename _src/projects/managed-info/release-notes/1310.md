**Features & improvements**

- Added a managed configuration option for EMM administrators to show or hide the System Freshness card in the Managed Device dashboard.
- Improved System Freshness data handling: current CVE coverage is retained for offline use, refreshed when it is no longer current, and no longer checked again each time the panel is opened.
- Update availability now remains Unknown when an update provider cannot return a result, rather than being reported as no update.

**Fixes**

- Fixed low-battery metadata collection on Android 8 and earlier.
