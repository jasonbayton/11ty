**Features & improvements**

- Introducing System Freshness on Android 11 and later. It brings together installed Android and Google Play system patch levels, locally reported update availability, published Android Security Bulletin data, CVE coverage, and kernel LTS support where available.
- Expanded uploaded device metadata with boot count; battery charge, current, and energy measurements; power-saving, idle, interactive, standby, battery-optimisation, and thermal state; network health; automatic time and time-zone settings; MANAGED INFO runtime information; and memory-pressure state.
- Upload metadata now includes the locally reported availability and last-check time for Android system and Google Play system updates, when Android supplies it.
- Updated AMAPI SDK, Kotlin version, and build dependencies.
