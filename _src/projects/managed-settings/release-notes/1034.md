**Features & improvements**

- Show the target app's icon for custom activity shortcuts, with a launch icon when app artwork is unavailable.
- Give broadcast and service actions their own icons to make the action types easier to identify.
- Let administrators rename **Organisation settings** through the **Custom intents section title** managed configuration (`customIntentsTitle`). Leave it blank to use the default heading. A licensed organisation ID is optional.
- Refresh app icons when returning to MANAGED SETTINGS while keeping the existing custom-action rows in place.

See the [custom intents guide](/projects/managed-settings/support/custom-intents/) for configuration examples.

**Fixes**

- Save managed settings before preparing the local PING reporting snapshot. A snapshot failure is logged after the settings have been saved.
- Correct the `managedConfigReceived` value in reporting snapshots for applied and withdrawn policy.

**Known issues**

Some OEMs/devices do not support AOSP settings intents. APN settings can also return or fail inside the device's Settings app after a launch is accepted.

OEM/device support and the reporting process are documented under [OEM support](/projects/managed-settings/support/oem-support/).
