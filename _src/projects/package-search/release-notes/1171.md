**Features & improvements**

- Added crash and handled-error reporting. Reports are queued offline and sent when connectivity returns.
- Reduced app size with release code and resource optimisation.

**Fixes**

- Fixed inventory discovery for apps installed only in another profile, including work profiles. Opening details for apps in another profile remains unavailable.
- Corrected permission grant states shown in app details.
- Prevented overlapping device identifier lookups during activation.
