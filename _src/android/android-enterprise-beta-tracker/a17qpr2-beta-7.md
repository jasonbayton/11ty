**Track:** QPR2 Beta | **Predecessor:** [QPR2 Beta 6](/android/android-enterprise-beta-tracker/a17qpr2-beta-7/) | **Milestone:** December 2026 stable

No enterprise-surface changes in this build. CP41.260831.016 is the October security patch for the QPR2 beta track, released on October 7. The framework and server-side device policy code are functionally identical to the previous build - all differences are decompilation artefacts (lambda renumbering, resource ID shifts) and updated localisation strings.
